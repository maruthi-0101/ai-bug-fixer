# AI Bug Fixer

An AI-powered tool to analyze and fix Python code bugs using Large Language Models.

## 📁 Project Structure

```
ai-bug-fixer/
├── app.py              # Gradio web application
├── bug_fixer.py        # Bug analysis and fixing logic
├── prompts.py          # LLM prompt templates
├── requirements.txt    # Python dependencies
├── README.md           # Project documentation
└── data/
    └── python_errors.txt   # Sample Python errors for testing
```

## � Setup

```bash
# Create virtual environment
python -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

## � Usage

```bash
python app.py
```
